# Архив старых исходников

Эта папка **не используется сайтом**. Она сохранена только для истории.

- `data/` — старые JSON-исходники. Они старше, чем `js/data.js`.
- `js-src/` — старые исходники JavaScript. Они старше, чем `js/app.js`.

Живые файлы сайта находятся в корне:

- `js/data.js` — все данные и тексты;
- `js/app.js` — весь код приложения;
- `css/style.css` — оформление;
- `index.html` — оболочка.

Не редактируйте эту папку и не собирайте сайт из неё. Старые скрипты `build_data.py` и `build_pdf_index.py` в репозитории отсутствуют, а команда `cat js/src/... > js/app.js` заменила бы новый код старым.

Если когда-нибудь понадобится вернуть нормальную сборку из исходников, это нужно делать как отдельную задачу: восстановить источники, собрать `js/data.js` и `js/app.js`, сравнить результат с текущими файлами и проверить сайт. Без такой проверки старые исходники использовать нельзя.
