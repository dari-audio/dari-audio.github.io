# Дари · Аудирование

Русскоязычный сайт-курс аудирования по дари на основе открытого архива DLIFLC (2005 и 2016 годы). Это статический сайт: HTML, CSS и JavaScript без сборки, базы данных и серверной части. Прогресс хранится только в браузере.

## Что внутри

- **Алфавит** — 33 буквы с формами, звучанием и примерами, 41 аудиозапись и 31 PDF-пропись.
- **26 вводных уроков A–Z** — первые шаги по буквам и звукам.
- **40 полных уроков** — словарь, рассказы, домашние задания, упражнения и аутентичные записи: 206 аудиодорожек и 40 PDF, всё сохранено локально.
- **Словарь** — 5 тематических наборов, 98 карточек и 662 озвученные записи, плюс 6 аудиотренажёров.
- **Практика** — викторина и карточки для повторения.
- **Аудиотека** — весь архив DLIFLC: 8 разделов, 179 папок и 2 387 файлов, в том числе 2 091 аудио и 238 PDF. Аудио слушается через встроенный плеер Google Drive, поэтому нужен интернет. Для 142 записей из разговоров, дискуссий, рассказов и карточек добавлены прямые кнопки «Скрипт» и «Задания», которые открывают общий PDF сразу на нужной странице.
- **Прогресс** — XP, серия дней, отметки букв, уроков и слов. Хранится в `localStorage` под ключом `dari-progress-v1`; сбросить можно на странице «О проекте».

## Быстрый запуск

### macOS

1. Дважды щёлкните `start.command` в папке проекта.
2. Откроется Терминал и браузер с адресом `http://localhost:8080`.
3. Чтобы остановить сайт, нажмите `Ctrl+C` в Терминале или закройте его окно.

Если macOS не разрешает запуск, щёлкните по `start.command` правой кнопкой → «Открыть» → «Открыть». Либо запустите вручную:

```bash
cd "/Users/arsenii/Desktop/Сайт с аудированиями по дари"
python3 -m http.server 8080
```

Затем откройте <http://localhost:8080>.

> Не открывайте `index.html` двойным щелчком через `file://`: браузер ограничит часть возможностей. Нужен локальный HTTP-сервер, команда выше уже это делает.

### Windows / Linux

В папке проекта выполните:

```bash
python3 -m http.server 8080
```

и откройте <http://localhost:8080>. На Windows вместо `python3` может понадобиться `python`.

### Доступ по локальной сети

Если вы и собеседник в одной Wi-Fi-сети, узнайте IP-адрес Mac:

```bash
ipconfig getifaddr en0
```

и откройте `http://<IP>:8080`, например `http://10.19.67.245:8080`. При первом запуске macOS может спросить, разрешить ли Python входящие соединения, — разрешите.

## Структура проекта

```text
index.html                 оболочка приложения

js/app.js                  рабочий JavaScript (собран из js/src)

js/src/01-core.js          утилиты, состояние, плеер, модальные окна
js/src/02-views.js         главная, алфавит, вводные уроки, уроки
js/src/03-views.js         словарь, практика, аудиотека, поиск, маршруты
assets/audio/alphabet/     41 запись алфавита
assets/audio/vocab/        662 записи словаря
assets/audio/lessons/      206 записей сорока уроков
assets/pdfs/alphabet/      31 PDF-пропись
assets/pdfs/lessons/       40 PDF-уроков
assets/pdfs/library/       6 общих PDF со скриптами и заданиями
assets/fonts/              локальные шрифты
data/                      исходные JSON, дерево архива и карта страниц PDF
build_data.py              сборка js/data.js
scan_drive.py              повторное сканирование публичного Drive
build_pdf_index.py         загрузка PDF и построение карты страниц
```

## Как обновить данные

Все данные приложения лежат в `data/` и `assets/`. После правок выполните:

```bash
python3 build_data.py
```

Скрипт пересоберёт `js/data.js`: списки букв, уроков, словарных карточек, полное дерево аудиотеки и статистику. Пути к локальным аудиофайлам и PDF берутся из структуры `assets/`, поэтому сохраняйте принятые имена папок и файлов. Для аудио из `4. Тексты` и карточек 41–80 скрипт сопоставляет названия записей с картой страниц `data/pdf-index.json` и добавляет ссылки на нужные страницы.

Если архив на Google Drive изменился, сначала обновите дерево:

```bash
python3 scan_drive.py --workers 6 --refresh
python3 build_pdf_index.py
python3 build_data.py
```

Если вы меняли исходники в `js/src/`, пересоберите рабочий файл:

```bash
cat js/src/01-core.js js/src/02-views.js js/src/03-views.js > js/app.js
```

## Публикация в интернете

Сайт статический, поэтому подойдёт любой хостинг статики. Папка занимает около 400 МБ, из них большая часть — аудио и PDF; проверьте лимиты выбранного тарифа.

### GitHub Pages

```bash
cd "/Users/arsenii/Desktop/Сайт с аудированиями по дари"
git init
git add .
git commit -m "Дари · Аудирование"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Затем в репозитории: **Settings → Pages → Deploy from a branch → main / (root)**. Через несколько минут сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ВАШ_РЕПОЗИТОРИЙ/`.

### Netlify Drop

Откройте <https://app.netlify.com/drop> и перетащите папку проекта целиком. Netlify выдаст ссылку вида `https://имя.netlify.app`. Если сервис ограничит размер загрузки, используйте GitHub Pages или Cloudflare Pages.

Маршрутизация выполнена через `#/...`, поэтому настройка «перенаправлять всё на index.html» не требуется.

## Технические заметки

- Приложение не использует сборщик и внешние CDN: шрифты и все основные аудиофайлы лежат локально.
- Аудиотека ссылается на Google Drive. Плеер Drive может загружаться 10–20 секунд; в модальном окне есть кнопки «Открыть в Drive» и «Скачать аудио» на случай, если встроенный плеер недоступен.
- Для PDF нужен браузер со встроенным просмотрщиком (Chrome, Edge, Safari).
- Горячие клавиши: `⌘K` / `Ctrl+K` — поиск по сайту, `Esc` — закрыть окно, `Enter` / `Space` — перевернуть карточку.
